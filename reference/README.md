# 原笔记中的 GPT 实现

`gpt_from_original.py` 来自 self attention 原笔记第 42 个单元（0-based 41），代码原样提取。
与入门路径分开存放：它有 GPT-2 风格模型结构、生成和预训练权重加载接口，但没有语料处理和训练入口。
原笔记“与官方完全等价”的表述未经权重级数值验证；本项目仅验证了微型配置的前向、反向和生成。
没有下载或验证 GPT-2 预训练权重。调用 `from_pretrained` 还需要额外安装 transformers。
原代码有 NanoGPT 风格结构；公开复用前应核对最初来源及许可证，原注释中的两个参考链接予以保留。
不要直接运行默认 12 层/768 维配置来做入门测试。
